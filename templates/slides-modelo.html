Guia prático

Eu não cliquei em “Publicar” para postar isto.

Um script de ~120 linhas fez isso pela API oficial do LinkedIn.
5 passos. Sem ferramenta paga.

Passo
01

Tenha uma LinkedIn Page

O app de desenvolvedor precisa estar ligado a uma página de empresa da qual você é administrador.

Não tem uma? Crie em linkedin.com/company/setup/new. Pode ser uma página simples, com o seu nome ou a sua marca.

02

Crie um app de desenvolvedor

Em linkedin.com/developers/apps, clique em Create app.

Nome, página e logo. Só isso.
O logo é obrigatório: imagem quadrada com pelo menos 100 px.

Peça acesso a 2 produtos

Na aba Products do app, clique em Request access em:

✓

✓
Sign In with LinkedIn using OpenID Connect

No meu caso, os dois foram liberados na hora.

Passo
04

Gere o token de acesso

No OAuth Token Generator, selecione o seu app e marque os escopos:

openidprofilew_member_social

Esse token é a chave para postar em seu nome. Guarde num arquivo .env e nunca compartilhe.

Passo
05

Publique com 2 chamadas

# 1. descobre quem é você
GET  /v2/userinfo
     → urn:li:person:…

# 2. publica o post
POST /v2/ugcPosts
     { author, texto, visibilidade }

Em Node.js puro, sem instalar nenhuma biblioteca.

Antes de começar

3 armadilhas que me custaram tempo

1

O nome do app não pode ter "LinkedIn"

O formulário recusa e não explica muito bem por quê.

2

Páginas com o mesmo nome

A busca selecionou outra empresa. Confira o ID numérico: esse vínculo não pode ser desfeito.

3

O token expira em ~60 dias

Quando aparecer erro 401, é só gerar outro no mesmo lugar.
